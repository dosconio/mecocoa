## 系统日期时间

Systime 保存 UTC 时间，由嘀嗒推进。

TIME 系统调用只有 unit 一个输入，无缓冲区参数：

| unit | 返回 |
|---|---|
| 0 | 开机秒数 |
| 1 | 开机毫秒数 |
| 0x10 | 当地日期 BCD：0xYYYYMMDD |
| 0x11 | 当地时间 BCD：0x00HHMMSS |
| 0x20 | UTC 秒数，按原生有符号位宽截断；日期无效时返回 -1 |
| 0x21 | 系统日期是否有效，0/1 |
| 0x22 | UTC 以东的固定偏移分钟数 |

sysgettime(timeval_t*) 先后检查有效性，取得秒级时间，mic 置 0；失败不改输出，返回负 errno。必须按状态判断成功，合法 UTC 秒数也可以是 -1。32 位平台的秒数按 32 位有符号数截断，不提供跨系统调用的完整 64 位时间传输。

用户库 time() 读取 UTC 秒数；gmtime() 按 UTC 换算，localtime()/mktime() 使用 systimeoffset() 返回的固定偏移，不处理夏令时。ribbon 无日期时显示 0/0/0 0:0:0；系统信息保留 unavailable。

统一挂载入口给所有文件系统提供 Systime::GetDateTime() 时间源。范围和格式限制由各文件系统后端自行处理，公共时间源没有 FAT 年份限制。用户库静态链接的程序需要随用户库更新重新链接。
